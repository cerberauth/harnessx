## Overview

Reporters are callbacks that fire during a scan. Use them to:
- Log progress in real-time
- Collect and aggregate results
- Integrate with external systems
- Implement custom output formats

## Reporter interface

```go
type Reporter interface {
  OnScanStart(target Target, totalChecks int)
  OnCheckStart(check Check, target Target, resource *Resource)
  OnCheckComplete(result Result)
  OnScanComplete(summary ScanSummary)
}
```

## Basic reporter

```go
type SimpleReporter struct{}

func (r *SimpleReporter) OnScanStart(_ harnessx.Target, totalChecks int) {
  fmt.Printf("Starting scan: %d checks\n", totalChecks)
}

func (r *SimpleReporter) OnCheckStart(check harnessx.Check, _ harnessx.Target, _ *harnessx.Resource) {
  fmt.Println("Starting:", check.ID)
}

func (r *SimpleReporter) OnCheckComplete(result harnessx.Result) {
  status := "✓"
  if result.Err != nil {
    status = "✗"
  }
  if result.Skipped {
    status = "○"
  }
  fmt.Println(status, result.CheckID)
}

func (r *SimpleReporter) OnScanComplete(summary harnessx.ScanSummary) {
  fmt.Println("Scan complete.")
  fmt.Println("Total:", summary.TotalChecks)
  fmt.Println("Executed:", summary.Executed)
  fmt.Println("Failed:", summary.Failed)
  fmt.Println("Skipped:", summary.Skipped)
}

engine := harnessx.New(
  harnessx.WithReporters(&SimpleReporter{}),
)
```

## Collecting results

```go
type ResultCollector struct {
  passed       []harnessx.CheckID
  failed       []harnessx.CheckID
  observations []harnessx.Observation
}

func (r *ResultCollector) OnScanStart(_ harnessx.Target, _ int) {}

func (r *ResultCollector) OnCheckStart(_ harnessx.Check, _ harnessx.Target, _ *harnessx.Resource) {}

func (r *ResultCollector) OnCheckComplete(result harnessx.Result) {
  if result.Err == nil && !result.Skipped {
    r.passed = append(r.passed, result.CheckID)
  } else if result.Err != nil {
    r.failed = append(r.failed, result.CheckID)
    r.observations = append(r.observations, result.Observations...)
  }
}

func (r *ResultCollector) OnScanComplete(_ harnessx.ScanSummary) {}


collector := &ResultCollector{}
engine := harnessx.New(harnessx.WithReporters(collector))

// After scan
for _, obs := range collector.observations {
  println(obs.Title, ":", obs.Description)
}
```

## JSON output

```go
type JSONReporter struct {
  checks []map[string]any
}

func (r *JSONReporter) OnScanStart(_ harnessx.Target, _ int) {}

func (r *JSONReporter) OnCheckStart(check harnessx.Check, _ harnessx.Target, _ *harnessx.Resource) {
  r.checks = append(r.checks, map[string]any{
    "id":    check.ID,
    "start": time.Now(),
  })
}

func (r *JSONReporter) OnCheckComplete(result harnessx.Result) {
  for i, check := range r.checks {
    if check["id"] == result.CheckID {
      r.checks[i]["end"] = time.Now()
      r.checks[i]["skipped"] = result.Skipped
      r.checks[i]["err"] = result.Err
      if len(result.Observations) > 0 {
        r.checks[i]["observations"] = result.Observations
      }
      break
    }
  }
}

func (r *JSONReporter) OnScanComplete(summary harnessx.ScanSummary) {
  data := map[string]any{
    "summary": summary,
    "checks":  r.checks,
  }
  b, _ := json.MarshalIndent(data, "", "  ")
  fmt.Println(string(b))
}
```

## Progress bar reporter

`OnScanStart` fires before any check runs and provides the total check count, making it straightforward to track progress.

```go
import "sync"

type ProgressReporter struct {
  mu    sync.Mutex
  total int
  done  int
}

func (r *ProgressReporter) OnScanStart(_ harnessx.Target, totalChecks int) {
  r.mu.Lock()
  r.total = totalChecks
  r.mu.Unlock()
}

func (r *ProgressReporter) OnCheckStart(_ harnessx.Check, _ harnessx.Target, _ *harnessx.Resource) {}

func (r *ProgressReporter) OnCheckComplete(result harnessx.Result) {
  r.mu.Lock()
  defer r.mu.Unlock()
  r.done++
  percent := r.done * 100 / r.total
  if percent > 100 {
    percent = 100
  }
  fmt.Printf("[%d%%] %d/%d\n", percent, r.done, r.total)
}

func (r *ProgressReporter) OnScanComplete(summary harnessx.ScanSummary) {
  fmt.Println("Done!")
}

engine := harnessx.New(harnessx.WithReporters(&ProgressReporter{}))
```

:::note
For `ScopePerResource` checks, `OnCheckComplete` fires once per resource. The `done` counter may exceed `totalChecks` on scans with many resources — clamp to 100% as shown above.
:::

## Multiple reporters

Pass multiple reporters directly to `WithReporters`:

```go
engine := harnessx.New(
  harnessx.WithReporters(
    &SimpleReporter{},
    &ResultCollector{},
    &JSONReporter{},
  ),
)
```

For dynamic reporter lists, spread the slice:

```go
var list []harnessx.Reporter
list = append(list, &SimpleReporter{})
list = append(list, &ResultCollector{})

engine := harnessx.New(
  harnessx.WithReporters(list...),
)
```

## Built-in text and JSON reporters

For CLI tools, examples and piping a scan into other programs, the `reporters` sub-package has two ready-made reporters that write to any `io.Writer`:

```go
// One line per finished check, its observations indented beneath it, then a summary.
engine := harnessx.New(harnessx.WithReporters(reporters.NewTextReporter(os.Stdout)))

// JSON Lines: a scan_start, one check_complete per check (per resource), and a scan_complete.
engine := harnessx.New(harnessx.WithReporters(reporters.NewJSONReporter(os.Stdout)))
```

Both are safe for concurrent use and never interrupt a scan on a write error; `Err()` returns the first one.

## Per-call reporters

`WithRunReporters` gives a single `Run` or `RunScenario` call its own reporters, in place of the engine's (and of `Scenario.Reporters`), so a shared engine does not need a `Scenario` just to change them:

```go
summary, err := engine.Run(ctx, target, harnessx.WithRunReporters(reporters.NewTextReporter(os.Stdout)))
```

## OpenTelemetry reporter

The `reporters` sub-package provides `OTelReporter`, which emits spans and metrics via OpenTelemetry.

```go
import "github.com/cerberauth/harnessx/reporters"

otelReporter, err := reporters.NewOTelReporter(ctx, tracer, meter)
if err != nil {
  log.Fatal(err)
}

// Optional: override the default "harnessx" metric/span prefix
otelReporter, err = reporters.NewOTelReporter(ctx, tracer, meter,
  reporters.WithPrefix("myapp"),
)

engine := harnessx.New(
  harnessx.WithReporters(otelReporter),
)
```

Spans form a tree. A `{prefix}.scan` span, started when the scan starts and carrying `target.url` / `target.host`, is the parent of one `{prefix}.check` span per check execution (per resource, for a per-resource check). A skipped check has no span of its own; it is recorded as a `check.skipped` event on the scan span, with its `check.id`, `resource.id` and `check.skip_reason`.

Metrics emitted (prefix defaults to `harnessx`):

| Metric | Description |
|--------|-------------|
| `{prefix}.check.duration` | Per-check execution time |
| `{prefix}.check.executions` | Count of check executions |
| `{prefix}.observations` | Count of observations emitted |
| `{prefix}.scan.duration` | Total scan duration |

## Best practices

- Keep reporter logic fast (it runs on the critical path)
- Use sync.Mutex if your reporter maintains state
- Don't modify scan state or results in a reporter
- Use `OnScanComplete` for final aggregation
- Implement `OnCheckStart` for real-time visibility
