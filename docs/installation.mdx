## Requirements

- **Go 1.26** or later

## Install with go get

<Steps>

1. **Add harnessx to your project**

   ```bash
   go get github.com/cerberauth/harnessx
   ```

2. **Import in your code**

   ```go
   import "github.com/cerberauth/harnessx"
   ```

3. **Verify**

   ```bash
   go mod tidy
   go build ./...
   ```

</Steps>

## Dependencies

The root `harnessx` package and `probe` depend only on the Go standard library and `golang.org/x/time` (the rate limiter). Third-party parsers and SDKs are compiled in only if you import the package that needs them:

- `checkdef` — YAML and TOML parsers
- `reporters` — OpenTelemetry API
