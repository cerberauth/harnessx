## Types

### Target

Represents what you're scanning.

```go
type Target struct {
  ID string
}
```

### Resource

Discovered by checks and consumed by dependent per-resource checks.

```go
type Resource struct {
  ID       string
  Type     string
  Metadata map[string]any
}
```

### CheckID

Unique identifier for a check. Type alias for `string`.

```go
type CheckID string
```

### CheckScope

Where a check runs.

```go
type CheckScope string

const (
  ScopeGlobal      CheckScope = "global"
  ScopePerResource CheckScope = "per-resource"
)
```

### Observation

An issue or noteworthy outcome found by a check.

```go
type Observation struct {
  CheckID     CheckID
  ResourceID  string
  Title       string
  Description string
  Evidence    string
  Metadata    map[string]string
}
```

### Result

The result of a single check execution.

```go
type Result struct {
  Skipped      bool
  Observations []Observation
  Resources    []Resource
  Duration     time.Duration
  Err          error
}
```

### Snapshot / Baseline

A captured response, reduced to what a comparator needs. `Baseline` is an alias for `Snapshot`, used when it's held up as the expected/reference value.

```go
type Snapshot struct {
  StatusCode int
  Header     http.Header
  Body       []byte
  Duration   time.Duration
  Data       any
}
type Baseline = Snapshot
```

### BaselineSource

Resolves the baseline for a resource. `ok=false` means no baseline is available and the comparison check skips.

```go
type BaselineSource func(ctx context.Context, target Target, resource Resource, store ResultStore) (Baseline, bool)

func StaticBaseline(b Baseline) BaselineSource
func BaselineFromResource() BaselineSource
func BaselineFromCheck(id CheckID) BaselineSource
```

### BaselineComparator

Compares a baseline against a freshly captured snapshot and returns any resulting `Observation`s.

```go
type BaselineComparator func(baseline, current Snapshot) []Observation

func CompareStatusCode(baseline, current Snapshot) []Observation // default comparator
```

### BaselineCheckConfig

Configures a baseline-comparison check.

```go
type BaselineCheckConfig struct {
  ID          CheckID
  Name        string
  Description string
  DependsOn   []CheckID
  Baseline    BaselineSource
  Capture     func(ctx context.Context, target Target, resource Resource, store ResultStore) (Snapshot, error)
  Compare     BaselineComparator // nil -> CompareStatusCode
  Timeout     time.Duration
  Concurrency int
}

func NewBaselineCheck(cfg BaselineCheckConfig) Check
func CaptureBaselineCheck(id CheckID, name string, capture func(ctx context.Context, target Target, resource Resource, store ResultStore) (Snapshot, error)) Check
```

### GlobalBaselineSource / GlobalCapture

`ScopeGlobal` counterparts of `BaselineSource` and the `Capture` func — no `Resource` param, for targets with no per-resource dimension.

```go
type GlobalBaselineSource func(ctx context.Context, target Target, store ResultStore) (Baseline, bool)
type GlobalCapture func(ctx context.Context, target Target, store ResultStore) (Snapshot, error)

func StaticGlobalBaseline(b Baseline) GlobalBaselineSource
func BaselineFromGlobalCheck(id CheckID) GlobalBaselineSource
```

### GlobalBaselineCheckConfig

`ScopeGlobal` counterpart of `BaselineCheckConfig`.

```go
type GlobalBaselineCheckConfig struct {
  ID          CheckID
  Name        string
  Description string
  DependsOn   []CheckID
  Baseline    GlobalBaselineSource
  Capture     GlobalCapture
  Compare     BaselineComparator // nil -> CompareStatusCode
  Timeout     time.Duration
}

func NewGlobalBaselineCheck(cfg GlobalBaselineCheckConfig) Check
func CaptureGlobalBaselineCheck(id CheckID, name string, capture GlobalCapture) Check
```

### Request building

`probe` package. `NewRequest` is the single entry point for building an outgoing HTTP request; small named `RequestMutator` functions compose onto it to shape headers, cookies, query params, or credentials.

```go
type RequestMutator func(*http.Request) error
type RequestBuilder func(ctx context.Context) (*http.Request, error)

func NewRequest(ctx context.Context, method, target string, body io.Reader, mutators ...RequestMutator) (*http.Request, error)

func WithHeader(name, value string) RequestMutator
func WithCookie(cookie *http.Cookie) RequestMutator
func WithQuery(name, value string) RequestMutator
```

`NewRequestFromResource` (root `harnessx` package) is a convenience over `NewRequest` for a `Resource`, defaulting to `GET` when `Resource.Method` is empty:

```go
func NewRequestFromResource(ctx context.Context, r Resource, mutators ...probe.RequestMutator) (*http.Request, error)
```

### Credential mutators

`probe` package. One thin `RequestMutator` per real-world auth use case — place an arbitrary secret/credential (a token, API key, session ID, basic-auth pair, ...) on an outgoing request.

```go
func WithBearerToken(token string) RequestMutator                // Authorization: Bearer <token>
func WithBasicAuth(username, password string) RequestMutator     // Authorization: Basic <base64>
func WithAPIKeyHeader(name, value string) RequestMutator          // arbitrary header, e.g. X-API-Key
func WithAPIKeyQuery(name, value string) RequestMutator           // arbitrary query param
func WithAuthCookie(name, value string) RequestMutator            // cookie, Secure+HttpOnly+SameSite=Strict
func WithFormCredential(name, value string) RequestMutator        // urlencoded form body field, switches method to POST
```

### ProbeAndCompareBaseline

Sends the request returned by a `probe.RequestBuilder` via `probe.Do`, and diffs the result against the baseline stored under `baselineID` using `CompareStatusCode`. Useful for one-off probes (credential swaps, header/param tampering, auth-bypass checks) that don't need the full `NewBaselineCheck` wiring.

```go
func ProbeAndCompareBaseline(ctx context.Context, p *probe.Probe, build probe.RequestBuilder, store ResultStore, baselineID CheckID) (Snapshot, bool, error)
```

Returns the captured `Snapshot` (with the full response header/body/duration) and whether it deviated from the baseline. Building a `Result`/`Observation` from that is left to the caller.

### Check

A check to execute.

```go
type Check struct {
  ID          CheckID
  Scope       CheckScope
  Timeout     time.Duration
  DependsOn   []CheckID
  Condition   Condition
  Run         func(context.Context, Target) (Result, error)
  RunResource func(context.Context, Target, Resource) (Result, error)
}
```

**Fields:**
- `ID`: Unique identifier (required)
- `Scope`: `ScopeGlobal` or `ScopePerResource` (required)
- `Timeout`: Max execution time (optional, no timeout if 0)
- `DependsOn`: List of check IDs this depends on (optional)
- `Condition`: Skip condition (optional)
- `Run`: Function to run for global checks (required if `Scope == ScopeGlobal`)
- `RunResource`: Function to run for per-resource checks (required if `Scope == ScopePerResource`)

### CheckDef

`checkdef` package (`github.com/cerberauth/harnessx/checkdef`). Declarative metadata for a `Check` — everything except behavior — parsed from an embedded YAML, TOML, or JSON definition file instead of hand-assembled in Go. Kept out of the root package so the core engine has no third-party dependencies; only importers of `checkdef` pull in a YAML/TOML parser.

```go
type CheckDef struct {
  ID          string
  Name        string
  Description string
  Link        string
  Tags        []string
  DependsOn   []string
  CVSSVector  string
  CVSSScore   float64
  CWEID       string
  CAPECID     string
  OWASP       string
  Extra       map[string]any // def-specific fields this package doesn't model yet, nested under "extra"
}

func (d CheckDef) DependsOnIDs() []harnessx.CheckID

func MustParseCheckDefYAML(pkg string, data []byte) CheckDef
func MustParseCheckDefTOML(pkg string, data []byte) CheckDef
func MustParseCheckDefJSON(pkg string, data []byte) CheckDef
```

Each `MustParse*` panics, prefixed with `pkg`, on malformed input — definitions are typically parsed once at `init()` time from an `//go:embed`ded file, so a bad definition is a build-time bug rather than something to recover from at runtime.

### NewCheck / NewResourceCheck

`checkdef` package. Build a `harnessx.Check` from a `CheckDef` plus a run function, wiring `ID`/`Name`/`Description`/`Link`/`Tags`/`DependsOn` for you. `NewCheck` sets `Scope: ScopeGlobal`; `NewResourceCheck` sets `Scope: ScopePerResource`.

```go
func NewCheck(def CheckDef, run harnessx.CheckFunc, opts ...Option) harnessx.Check
func NewResourceCheck(def CheckDef, run harnessx.ResourceCheckFunc, opts ...Option) harnessx.Check
```

**Options** (everything on `harnessx.Check` not already carried by `CheckDef` or the run function):

```go
func WithSkip(s harnessx.SkipDecision) Option
func WithConditions(c ...harnessx.Condition) Option
func WithTimeout(d time.Duration) Option
func WithConcurrency(n int) Option // meaningful on NewResourceCheck only
```

### Condition

A predicate that determines if a check should run.

```go
type Condition interface {
  Eval(context.Context, ResultStore) bool
}
```

**Constructors:**
- `IfCheckPassed(CheckID)` — run if check passed
- `IfCheckObserved(CheckID)` — run if check produced at least one observation
- `IfCheckSkipped(CheckID)` — run if check was skipped
- `All(...Condition)` — all conditions must be true
- `Any(...Condition)` — at least one must be true
- `Not(Condition)` — negate condition

### ResultStore

Read-only view of check results. Available to reporters and conditions.

```go
type ResultStore interface {
  Get(CheckID) Result
  All() map[CheckID]Result
}
```

### ScanSummary

Summary of scan results.

```go
type ScanSummary struct {
  Total   int
  Passed  int
  Failed  int
  Skipped int
}
```

### Reporter

Callback interface for tracking scan progress.

```go
type Reporter interface {
  OnScanStart(target Target, totalChecks int)
  OnCheckStart(check Check, target Target, resource *Resource)
  OnCheckComplete(result Result)
  OnScanComplete(summary ScanSummary)
}
```

**Implementations:**
- `NoopReporter` — does nothing (useful as default)
- `reporters.OTelReporter` — emits spans and metrics via OpenTelemetry (`github.com/cerberauth/harnessx/reporters`)

### OTelReporter

```go
// reporters sub-package
func NewOTelReporter(ctx context.Context, tracer trace.Tracer, meter metric.Meter, opts ...OTelOption) *OTelReporter

type OTelOption func(*otelConfig)

func WithPrefix(prefix string) OTelOption
```

Metrics: `{prefix}.check.duration`, `{prefix}.check.executions`, `{prefix}.observations`, `{prefix}.scan.duration` (default prefix: `"harnessx"`).

### ScanError

Error returned by `Engine.Run()`.

```go
type ScanError struct {
  Err error // Underlying error
}

// Common error types:
var (
  ErrCycleDetected      // Circular dependency found
  ErrDuplicateCheckID   // Two checks have same ID
  ErrUnknownDependency  // Dependency not registered
  ErrNoChecks           // No checks registered
)
```

### Engine

Main orchestration engine.

```go
type Engine struct {
  // Private fields
}
```

**Methods:**

#### New

Create a new engine.

```go
func New(opts ...Option) *Engine
```

**Example:**
```go
engine := harnessx.New(
  harnessx.WithMaxConcurrency(4),
  harnessx.WithReporters(myReporter, otherReporter),
)
```

#### Register

Register one or more checks.

```go
func (e *Engine) Register(checks ...Check) error
```

**Returns:**
- `ErrDuplicateCheckID` if a check with the same ID exists
- `ErrCycleDetected` if adding the check would create a cycle
- `ErrUnknownDependency` if a dependency doesn't exist

**Example:**
```go
err := engine.Register(check1, check2)
if err != nil {
  panic(err)
}
```

#### Run

Execute all registered checks against a target.

```go
func (e *Engine) Run(ctx context.Context, target Target) (ScanSummary, error)
```

**Returns:**
- `ScanSummary` with counts of passed, failed, skipped
- `ScanError` on validation failure or check panic

**Example:**
```go
ctx := context.Background()
summary, err := engine.Run(ctx, target)
if err != nil {
  println("Scan error:", err)
}
```

## Options

### WithMaxConcurrency

Set max concurrent checks per level.

```go
func WithMaxConcurrency(n int) Option
```

**Default:** `1` (sequential execution)

### WithMaxResourceConcurrency

Set max concurrent per-resource checks.

```go
func WithMaxResourceConcurrency(n int) Option
```

**Default:** `1` (sequential execution)

### WithReporters

Set one or more reporter callbacks. Multiple reporters are automatically fanned out.

```go
func WithReporters(reporters ...Reporter) Option
```

**Default:** `NoopReporter()` if no reporters provided

## Execution Flow

1. **Validate**: Check for duplicates, missing dependencies, cycles
2. **Topological Sort**: Order checks into dependency levels using Kahn's algorithm
3. **Execute Levels**: For each level:
   - Take snapshot of prior results
   - Run independent checks in parallel (bounded by `MaxConcurrency`)
   - Wait for level to complete
4. **Per-Resource Checks**: For checks with `ScopePerResource`:
   - For each resource from dependencies:
     - Run check (bounded by `MaxResourceConcurrency`)
5. **Callbacks**: Call reporter on each start/complete, then on scan complete

## Error Handling

### Panics

If a check panics, the panic is recovered and recorded as a `ScanError`. The scan continues.

### Timeouts

If a check exceeds its timeout, it returns `context.DeadlineExceeded`. The check fails but the scan continues.

### Context Cancellation

If the root context is canceled, all running checks are canceled. The scan returns the context error.

## Common Patterns

### Check if scan succeeded

```go
summary, err := engine.Run(ctx, target)
if err != nil {
  panic(err)
}

if summary.Failed > 0 {
  println("Issues found!")
}
```

### Collect observations

```go
type Collector struct {
  observations []Observation
}

func (c *Collector) OnCheckComplete(checkID string, result Result) {
  if len(result.Observations) > 0 {
    c.observations = append(c.observations, result.Observations...)
  }
}

// ... use with engine
```

### Timeout entire scan

```go
ctx, cancel := context.WithTimeout(context.Background(), 60*time.Second)
defer cancel()

summary, err := engine.Run(ctx, target)
```
