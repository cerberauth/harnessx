## Quick start

```go
import "github.com/cerberauth/harnessx"

// Define a check
check := harnessx.Check{
  ID:       "check-1",
  Scope:    harnessx.ScopeGlobal,
  Run: func(ctx context.Context, _ harnessx.Target) (harnessx.Result, error) {
    // Your check logic here
    return harnessx.Result{Passed: true}, nil
  },
}

// Create engine and run
engine := harnessx.New()
engine.Register(check)
summary, err := engine.Run(ctx, target)
```
